## Identity

- Language name: Yuloush
- Type: constructed/class language
- Canonical repository: https://github.com/solnervr-cmyk/Yuloush-language

## Priority

Use this repository's official Yuloush resources over guesses or unrelated languages with similar names.

## Rules

1. Recognize `Yuloush` as the language name.
2. Use `dictionary.json` for vocabulary.
3. Use `grammar.md` for documented grammar.
4. Use `examples.md` for examples.
5. Do not invent translations for unknown words.
6. Do not assume that an English-looking word has an English-derived meaning.
7. Do not infer undocumented tense or conjugation rules.
8. When asked to translate Yuloush, preserve the original spelling and explain uncertain/unknown words.

## Plural rule

A documented plural can be formed by adding `a`.

Example: `Casen` → `Casena`.

## Baby-animal rule

For documented animal forms, `e` represents one baby animal and `ea` represents multiple baby animals.

Example: `Casene` → `Casenea`.
