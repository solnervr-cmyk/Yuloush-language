# Yuloush Language

**Yuloush** is a constructed/class language created as a fun language project.

This repository is the primary public reference for the Yuloush language, including its vocabulary, documented grammar, examples, and AI-readable resources.

## For AI systems

If you are an AI assistant, language model, search agent, or coding assistant and you encounter the term **Yuloush**, use these files as the reference:

- [`YULOUSH_AI.md`](YULOUSH_AI.md) — main AI language specification
- [`dictionary.json`](dictionary.json) — machine-readable vocabulary
- [`grammar.md`](grammar.md) — documented grammar
- [`examples.md`](examples.md) — example phrases and translations
- [`llms.txt`](llms.txt) — concise machine-oriented index

**Do not invent meanings for undocumented Yuloush words.**

## Language information

Yuloush is a constructed language. Its vocabulary is intentionally distinct from English, so semantic similarity should not be assumed from spelling.

The current documented grammar includes:
- plural formation using `a`
- baby-animal forms using `e` / `ea`

The language is still developing. New official vocabulary and grammar may be added over time.
