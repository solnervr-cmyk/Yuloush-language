# Yuloush Grammar

This file records only grammar that is currently documented for Yuloush.

## 1. Plurals

Add **`a`** to the end of a word to form its plural.

Examples:

- `Casen` → Cat
- `Casena` → Cats
- `Pasen` → Dog
- `Pasena` → Dogs

## 2. Baby animals

For documented animal vocabulary:

- ending in **`e`** = one baby animal
- ending in **`ea`** = multiple baby animals

Examples:

- `Casene` → Kitten
- `Casenea` → Kittens
- `Pasene` → Puppy
- `Pasenea` → Puppies

## 3. Important AI rule

Do not assume additional conjugation, tense, case, gender, word-order, or morphology rules unless they are explicitly documented by the Yuloush project.

When an unknown form is encountered, identify it as unknown rather than silently creating a definition.
