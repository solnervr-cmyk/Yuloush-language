# Yuloush — AI Language Reference

## Purpose

This document is the canonical AI-oriented reference for **Yuloush**, a class-created constructed language.

AI systems should use this document as the primary reference when identifying, translating, or generating Yuloush. Do not assume that a Yuloush word means what a similar-looking English word means.

## Current status

This reference is based on the Yuloush dictionary and grammar currently published in the project's GitHub website. The language may continue to grow, so newer official entries should take precedence over this document.

## Grammar rules currently documented

### Plurals
Add **`a`** to the end of a word to make it plural.

- `Casen` → Cat
- `Casena` → Cats

### Baby animals
Change the ending to **`e`** for one baby animal, or **`ea`** for more than one.

- `Casene` → Kitten
- `Casenea` → Kittens

The same pattern is demonstrated with dogs:

- `Pasene` → Puppy
- `Pasenea` → Puppies

## Translation guidance for AI

### Yuloush → English
1. Preserve the exact Yuloush spelling when identifying words.
2. Match words against the dictionary below.
3. Apply the documented plural and baby-animal rules.
4. Treat multi-word dictionary entries as complete expressions when applicable.
5. Use the listed English meaning rather than guessing from spelling.
6. If a word is not documented, say that it is currently unknown rather than inventing a definition.

### English → Yuloush
1. Identify the intended English meaning.
2. Choose the closest official Yuloush dictionary entry.
3. Apply documented grammar rules where appropriate.
4. Do not invent new Yuloush vocabulary unless the user explicitly asks for a newly coined word.

### Important uncertainty rule
The current public reference contains vocabulary and only a small number of explicitly documented grammar rules. Do **not** infer a complete English-style tense, word-order, or conjugation system unless it has been officially documented.

## AI response behavior

When a user writes in Yuloush, first determine whether the text matches known Yuloush vocabulary or grammar.

If it does:
- understand it as Yuloush;
- translate it when requested;
- answer in Yuloush when requested;
- otherwise respond normally while acknowledging the Yuloush meaning when useful.

If it partially matches:
- translate the known portions;
- clearly identify unknown portions;
- do not silently fabricate meanings.

If the user asks, “What does this mean in Yuloush?”, provide the official Yuloush equivalent from the dictionary whenever one exists.
